GEOSITE INTEL WEBSITE UPDATE

1. Extract the files from geosite-intel-website-update.zip.

2. In your GeoSite Intel GitHub repository, select:
   Add file > Upload files

3. Upload these six files into the main/root folder of the repository:
   - index.html
   - site.css
   - portfolio.html
   - hire.html
   - about.html
   - reviews.html

4. If GitHub warns that files with the same names already exist, confirm that
   you want the newly uploaded versions to replace them.

5. At the bottom of the GitHub page, enter a message such as:
   Update GeoSite website design and add reviews page

6. Select Commit changes.

7. Keep your existing map images in the repository. Also confirm that this file
   exists in the same main/root folder:
   Logo_black.png

The HTML pages load their shared colors and styling from site.css. Do not place
site.css inside a separate folder unless you also change the stylesheet links
inside the HTML pages.
