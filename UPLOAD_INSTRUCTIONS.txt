GEOSITE INTEL BRAND UPDATE

1. Open the main/root folder of the GeoSite Intel GitHub repository.
2. Upload every file contained in this package.
3. Allow GitHub to replace the existing HTML and CSS files with these versions.
4. Keep all of your existing JPG case-study images in the repository.
5. Commit the changes.
6. Open geositeintel.com. The pages use a versioned stylesheet link so the
   corrected logo sizing should appear immediately.
7. If an already-open tab still shows the older version, press Ctrl+F5 once.

plans, and documents rather than direct file attachments. This avoids promising
an upload feature that is not available on the current form plan.
