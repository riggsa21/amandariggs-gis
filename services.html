Questions before you start

Frequently asked questions

Do we have to buy a new platform?

Not necessarily. Many bounded tasks can be handled by Python scripts or local tools using files and software you already have. Requirements and licenses are reviewed during scoping.

Can a script work with our Excel or CSV files?

Often yes. Feasibility depends on sample structure, expected variations, system permissions, and the requested result. A sample file is the best starting point.

Will the process run automatically without review?

That depends on risk and data quality. Some repetitive rules can run unattended; outputs involving ambiguous or sensitive inputs may require a staff review step.

How much does it cost?

Projects are quoted after reviewing the input files, number of steps, complexity, testing requirements, and support needs. There is no one-size-fits-all subscription price.

What if we need GIS automation?

GeoSite has experience creating repeatable QGIS/Python workflows for data preparation, spatial analysis, mapping, and quality checks. Review the GIS examples.
